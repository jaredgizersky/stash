# Security

`stash` runs locally and reads local Claude Code and Codex session files. Those transcripts can include prompts, file paths, command output, or secrets already present in your local agent logs.

Do not publish demo data, screenshots, or logs from your real `~/.claude`, `~/.codex`, or `~/.stash` directories without reviewing them first.

## Reporting

Please report security issues privately by opening a GitHub security advisory or contacting the repository owner. Do not file public issues for vulnerabilities or leaked sensitive data.
